实现一个完全离线的差分测试工作台，比较你编写的严格解析器与带三处明确缺陷的教学解析器；协议仅用于本题。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 帧格式为4字节大端长度、1字节类型、TLV载荷和4字节CRC32；TLV为1字节标签、2字节长度、值，标签0x20表示嵌套TLV，嵌套最多8层，单帧64KiB。实现逐字节增量解析，错误位置必须是原始流偏移。长度字段计入类型和TLV载荷但不含自身与CRC，CRC覆盖类型和载荷；顶层深度为0，标签0x01在同一层最多出现一次，其余未知标签作为不透明值保留。
2. 生成器同时支持保持结构的变异和破坏单一约束的变异；三个教学缺陷分别为长度少算一字节、重复关键标签接受、嵌套深度多接受一层。只把接受状态或消费边界不同归为差分，不能把随机异常直接算发现。
3. 失败最小化必须保留原差分分类，在截短、删除TLV及调整长度和校验和后重新验证；保存种子、原样字节、分类和重放命令，进程中断后恢复不得改变同一种子的生成序列。

必须覆盖的验收场景：固定种子稳定发现三类缺陷；最小化结果逐字节删除检查局部最小性；任意分块方式不得改变严格解析结论。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
